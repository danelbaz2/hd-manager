- Automatic caching (no duplicate API calls)
- Better performance
- Simpler code

## React Query Hooks Available

```typescript
// Users
const { data: users = [], isLoading } = useUsersQuery();

// Tasks
const { data: tasks = [], isLoading } = useTasksQuery();

// Tags
const { data: primaryTags = [] } = usePrimaryTagsQuery();
const { data: secondaryTags = [] } = useSecondaryTagsQuery();

// Contacts
const { data: contacts = [] } = useContactsQuery();

// History
const { data: history = [] } = useAllTasksHistoryQuery();
```

## WebSocket Integration

### New Architecture: RealtimeSyncProvider

A new `RealtimeSyncProvider` has been created at `src/socket/RealtimeSyncProvider.tsx`:

- Subscribes to all WebSocket events (tasks, users)
- Automatically invalidates React Query caches when updates arrive
- Uses `updateReactQueryCache()` for direct cache updates when `fullTask` data is available
- Falls back to `invalidateTaskQueries()` for simple invalidation

This provider is placed in `main.tsx` inside `SocketProvider`, before `SettingsProvider`.

### Socket Integration Functions

Available in `api/queries/socketIntegration.ts`:

- `invalidateTaskQueries()` - called on task socket events
- `invalidateUserQueries()` - called on user socket events
- `invalidateTagQueries()` - called on tag socket events
- `invalidateContactQueries()` - called on contact socket events
- `invalidateChatQueries()` - called on chat socket events
- `invalidateAllQueries()` - called on reconnect
- `updateReactQueryCache()` - direct cache update from WebSocket data
- `updateHistoryCache()` - direct history cache update
